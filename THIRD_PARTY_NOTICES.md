# Source and dependencies

The MEMS implementation reconstructs the micromachined-switch example in
M. Rewienski's 2003 dissertation, Section 2.2.2 and Appendix B. Its pressure
Laplacian uses the negative endpoint diagonal for the stated Neumann boundary
condition. The implementation contains no contact model or state clipping.

The LaTeX class and bundled fonts retain their original notices and licensing.
Lean, Mathlib, Python libraries and their dependencies retain their own licenses.
The pinned ProofWidgets patch concerns local dependency build configuration.

A license for this paper's original Python/Lean source has not yet been selected.
Publication of the source does not assign it a reuse license.
No third-party material is relicensed by this packaging work.
