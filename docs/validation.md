# Validation status

The source-only package has passed an independent short integration run from an
export under `/tmp`, installed into a temporary Python environment and launched
through its installed command from outside the dissertation. It generated fresh
physical data, trained both arms, evaluated reserved cases, verified normalized
nine- and nineteen-state interval certificates, generated figures and exact
Lean inputs, and compiled the manuscript. The main text remained ten pages.
The scientific qualification report correctly rejected the paper's instability
contrast and accuracy gates for this two-update, coarse-clock test.

Nine software contracts pass. They cover physical reconstruction, residual
envelopes, scripted recurrence gradients, checkpointed gradients across chunks,
directed-rounding witness checks, exact integer exports, source-only export and private audit/history exclusion,
componentwise plateau/stall handling and manuscript-freshness rejection.

The 86 exported general proof modules are unchanged from their reviewed
originals. Their package roots import successfully against the pinned local
build, and the nine named general results pass the standard axiom audit.
Scalar autonomous and sqrt(2)-control exports compile in Lean. A generated
autonomous matrix witness for the fresh nine-state smoke model also compiles
and passes its axiom audit. These checks reused local pinned dependencies;
they are not a claim of a new cold dependency-download build.

The full paper-clock training recipe and the complete full-size generated Lean
instance build have not yet passed an acceptance run. A clean Python dependency
installation ran out of disk space; the successful installed-command test
reused the scientific libraries already installed on this machine. The full
rehearsal requires about 1.1 GB free for local data and outputs, in addition to
space for any missing dependencies and proof caches. Training runtime and
convergence at the default settings have not yet been measured.

This is now the permanent source repository. The author explicitly waived a full
rehearsal for the cleanup/publication step. Its from-scratch recipe has not been
shown empirically equivalent to the historical warm-start chain. That remains
a stated validation limit, not a claim of reproduction. Nine software tests and
the recorded short integration checks provide the tested scope described above.
Historical experiments remain archived without deletion. The public package
excludes the two published-model-specific Lean instances; generated fresh matrix
checks do not inherit those results.
